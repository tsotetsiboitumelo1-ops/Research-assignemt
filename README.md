# 📚 BrightLearn Data Analytics – Research Assignment 1

## Foundations of Data Analytics & Data Science

This repository contains my **Research Assignment 1** completed as part of the **BrightLearn Data Analytics & Data Science course**.

The assignment focused on building a foundational understanding of **data analytics, data science, artificial intelligence, machine learning, APIs, cloud computing, data ethics and different careers in the data field**.
